# ATmega128 Line Tracer

ATmega128 기반 라인트레이서의 센서 보정, 라인 위치 추정, 모터 제어 및 주행 구간 처리를 구현한 C 펌웨어입니다.

## 주요 기능

- 8채널 ADC 센서 데이터 수집 및 센서별 최솟값·최댓값을 이용한 보정
- 센서 가중치를 이용한 라인 위치 추정
- 비례 이득(Pgain)에 따른 좌우 모터 속도 보정
- Timer 1·3 인터럽트 기반 모터 위상 제어와 가감속 테이블 활용
- 시작·종료·좌우 턴 마크 및 교차 구간 인식
- 구간 길이 기록과 2차 주행 모드
- LCD 메뉴와 3개 스위치를 통한 센서 튜닝 및 주행 파라미터 설정

## 개발 환경

- MCU: ATmega128
- 언어: C
- 컴파일러: CodeVisionAVR 문법 사용 (`mega128.h`, `interrupt [...]`, `#asm`)
- 주변 장치: 라인 센서, 좌우 모터, 문자 LCD, 스위치

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `line_tracer.c` | 업로드한 원본 라인트레이서 제어 코드 |
| `AccTable.h` | 가감속용 타이머 비교값 테이블 (`acctable.h` 원본, 파일명 대소문자 일치 처리) |
| `README.md` | 프로젝트 개요 및 빌드 준비 사항 |

## 빌드 준비

1. CodeVisionAVR에서 ATmega128 프로젝트를 생성합니다.
2. `line_tracer.c`를 프로젝트에 추가합니다.
3. 저장소의 `AccTable.h`를 소스와 같은 폴더에 두고 헤더 검색 경로를 확인합니다.
4. 실제 보드에 맞게 클록, 포트 연결, LCD 및 프로그래머 설정을 확인합니다.
5. 빌드 후 펌웨어를 보드에 업로드합니다.

첨부된 원본 `acctable.h`를 코드의 `#include "AccTable.h"`와 일치하도록 `AccTable.h`로 추가했습니다. 한글 주석 인코딩은 CP949에서 UTF-8로 변환했으며 테이블 수치는 변경하지 않았습니다. 백업 파일(`~`)과 컴파일 생성물은 포함하지 않았습니다.

**원본 테이블 확인 사항:** `ACC_TABLE_LENGTH`는 9999로 정의되어 있지만 실제 `table[]` 원소는 8690개입니다. 배열 접근 인덱스는 0~8689 범위인지 확인해야 합니다. 헤더 주석의 설정은 클록 20 MHz, 바퀴 지름 5.20 cm입니다. 실제 하드웨어와의 일치 여부를 확인하세요. 해당 컴파일러와 실물 하드웨어에서 빌드·주행 검증은 수행하지 않았습니다.

## 사용 흐름

센서 튜닝 → 속도·비례 이득 등 파라미터 설정 → 탐색 주행 → 구간 기록을 활용한 추가 주행

세부 동작과 메뉴 구성은 `line_tracer.c`를 참고하세요. 함수 이름이 `update_PID`이지만 현재 해당 함수의 조향 보정은 `Pgain`을 이용한 비례 제어입니다.
